# elder_med_agent
老年人用药安全 + 青少年眼部健康评估智能体（Streamlit Web应用）

## 📖 项目介绍
本项目是基于Streamlit搭建的健康评估智能体网页应用，包含两大评估模块：
1. 👵 老年人用药安全评估：语音/文字输入，评估老人用药风险，内置药品知识库，支持用药风险解读
2. 👀 青少年眼部健康评估：视力单OCR识别、用眼风险评估，生成护眼建议报告

支持语音录入、中英文双语切换、图片OCR识别，适合健康科普与居家健康自测。
